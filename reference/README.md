# Reference Material

This directory is for historical or contextual setup material that is not part of the active setup path.

Use `reference/` when a guide is still worth keeping for research or recovery, but should no longer be treated as a current `Setup Plan` or canonical `Resource Catalog` source.

## Navigation

The active setup path starts at the root [README](../README.md) and continues through [Setup Plans](../plans/README.md), the [Resource Catalog](../catalog/README.md), and [Inventory Exports](../exports/README.md).

Do not use `reference/` as the primary route for active Linux, macOS, or Android setup work.
