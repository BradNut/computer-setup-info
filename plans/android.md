# Android Setup Plan

Use this as the active Android setup route. Supporting `Resource Catalog` material lives in [catalog](../catalog/README.md), curated Android exports live in [exports/android](../exports/android/README.md), and historical material belongs in [reference](../reference/README.md).

## 1. Choose application sources — manual

Review the canonical [Android application catalog](../catalog/android-application-catalog.md). Each app lists a primary `Application Source` and optional alternates; validate the chosen source before installation. Historical notes are preserved in [reference/android/Applications.md](../reference/android/Applications.md) for research only.

## 2. Reconcile against the latest export — manual

Compare the chosen application set against the latest curated [Primary device export](../exports/android/primary-device.md) before finalizing the install.

## 3. Configure device-level needs — manual

Review backup, privacy, VPN, authentication, and sync choices before installing optional applications.

## Verification

Confirm installed apps use the intended source and permissions.
