# macOS Setup Plan

Use this as the active macOS setup route. Supporting `Resource Catalog` material lives in [catalog](../catalog/README.md), curated macOS exports live in [exports/macos](../exports/macos/README.md), and historical material belongs in [reference](../reference/README.md).

Use the shared desktop records below as the active path for cross-platform desktop decisions, then complete the macOS-specific follow-up from the canonical macOS catalog and latest curated export.

- Review [shared desktop software inventory](../catalog/shared-desktop-software.md).

## 2. Shared coding, terminal, and browser preferences — manual

- Apply [shared coding environment preferences](../catalog/shared-coding-environment-preferences.md).
- Apply [shared terminal preferences](../catalog/shared-terminal-preferences.md).
- Review [shared browser and extension choices](../catalog/shared-browser-and-extension-choices.md).

## 3. macOS-specific applications — manual

- Use the canonical [macOS application catalog](../catalog/macos-application-catalog.md) for macOS-only follow-up and macOS-specific install channels for shared apps.
- Reconcile the resulting application set against the latest curated [macOS inventory export](../exports/macos/primary-machine.md).

## Verification

Launch each selected application, confirm editor and terminal preferences, and verify the installed set still matches the curated macOS inventory export.
