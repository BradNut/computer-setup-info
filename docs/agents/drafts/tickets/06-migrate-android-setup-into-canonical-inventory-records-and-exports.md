## What to build

Move Android setup onto canonical Inventory Records and curated Inventory Exports. This slice should make the Android Setup Plan point to canonical Android inventory material, represent each Android application with a primary Application Source and optional alternates, and expose the latest curated Android Inventory Export through the active navigation path.

## Acceptance criteria

- [ ] The Android Setup Plan links to canonical Android inventory material.
- [ ] Android applications represent a primary Application Source with optional alternate sources.
- [ ] The latest curated Android Inventory Export is reachable from the Android Setup Plan.
- [ ] An Android app-selection and review path can be followed without relying on legacy Android navigation roots.

## Blocked by

- #1 — Establish the role-based documentation skeleton
- #2 — Enforce the navigation contract in documentation validation
- #3 — Migrate shared desktop resources into canonical Resource Catalog records
