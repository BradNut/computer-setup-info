## What to build

Promote shared cross-platform desktop concerns into canonical Resource Catalog material so Linux and macOS plans can point to one maintained source of truth. This slice should make shared software inventory, coding environment preferences, terminal preferences, browser or extension choices, and account or privacy decisions discoverable through the active role-based path.

## Acceptance criteria

- [ ] Shared cross-platform desktop concerns are represented as canonical Resource Catalog material.
- [ ] The active Setup Plans can link to the shared Resource Catalog material without relying on legacy platform notes.
- [ ] Shared records are navigable as shared concerns rather than duplicated platform lists.
- [ ] The resulting path is usable through links alone.

## Blocked by

- #1 — Establish the role-based documentation skeleton
- #2 — Enforce the navigation contract in documentation validation
