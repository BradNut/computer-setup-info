# Inventory Exports

This directory holds curated `Inventory Export` snapshots for active setup work.

Use exports to compare actual machine or device state against the intended `Inventory Record` material in the [Resource Catalog](../catalog/README.md).

## Active export areas

- Linux — export snapshots for Linux hosts and devices
- macOS — export snapshots for macOS hosts and devices
- Android — export snapshots for Android devices

## Navigation

Start from the root [README](../README.md), then choose an active [Setup Plan](../plans/README.md). Each active plan should link to its latest curated export.
